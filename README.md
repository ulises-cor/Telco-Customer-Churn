# Telco Customer Churn Prediction

This project uses machine learning to predict customer churn using Telco data.

## Goals
- Identify high-risk customer
- Improve retention strategies
- Showcase skills in data wrangling, EDA, and modeling

## Technologies
- Python
- Pandas, Numpy, Matplotlib, Seaborn
- Scikit-learn
- XGBoost

## Model Performance
- **XGBoost (Threshold 0.4):**
  - Accuracy: 76%
  - F1 Score (Churners): 0.58
  - Recall (Churners): 0.61

## Key Insights
- Month-to-month contracts, fiber optics, and electronic checks were strong churn indicators.
- Customer threshold tuning boosted model's ability to catch churners.
